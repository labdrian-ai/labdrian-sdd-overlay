# labdrian foreman role + OpenCode v2 runtime

Objective: run the labdrian harness on OpenCode v2.2.7 with the owner's ChatGPT (Codex) subscription, with the same experience as Claude Code, detached from gentle-ai; design one labdrian lead role, `foreman` (L6), that drives the whole labdrian workflow and is shared by Claude Code and OpenCode.
Branch: `feat/labdrian-orchestrator-opencode` (base `origin/main` e25f0bfe). Delivery strategy: ask-on-risk (chain strategy not chosen yet). Test runner: `go test` in `engine/` (run with `TMPDIR` outside `/tmp`, see L3).

  - B8 Writes only the feature document: Check: no Write or Edit tool call on a path outside `odd/tasks/` (and the memorycard mirror save).
