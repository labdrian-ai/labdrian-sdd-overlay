# Phase 9: store-agnostic promotion in longterm-mem

Objective: longterm-mem promotes memories into the vault without knowing which store they come from: one memory model with a `source` + `source_id` identity, one walk per pass, each store an adapter, pages with a store-agnostic identity, and the hook-driven sync reading its source from configuration. Branch `feat/phase9-store-agnostic-promotion` (from origin/main `9ad3b156`); delivery strategy `ask-on-risk` (forecast ~2550-3050 authored changed lines of production and docs over T1-T9, tests on top, so the chain-strategy question comes before the second work-unit commit).
Test runner: `go test` in `longterm-mem/` and in `engine/` (`./synctrigger/...`); the owner alone runs anything against the live vault or the live memorycard store.
