# labdrian-sdd-overlay

An end-to-end harness for solo software engineering and product development with AI agents: one person drives a goal from the idea to a merged, reviewed change, role agents do the work, and hooks enforce the rules. It deploys skills, agents and contracts to Claude Code, Codex, opencode and Pi with `labdrian apply`; Hermes counts as a runtime once its branch closes (audit-2026-11-25-4). Owner: labdrian (audit-2026-11-25-2).
