# Palette & Typography Reference

Distilled (not copied verbatim) from 4 real award-gallery sites. Every row cites the
source site(s) that informed it; all 4 sites are cited somewhere in this file.

| Aspect | Distilled direction | Source site(s) |
|--------|---------------------|-----------------|
| Base palette | Near-monochrome ground: off-white or warm-paper background paired with near-black or deep-ink text, avoiding pure `#fff`/`#000` | depoluxe.xyz, bymonolog.com |
| Accent | A single warm accent color (rust, amber, or clay), applied sparingly to links, small UI marks, or one hero element — never as a gradient | collection.industries |
| Typography | Editorial pairing: an oversized, characterful display face for headings + a restrained, legible body face. Explicitly NOT Inter, Roboto, or a generic system sans | bymonolog.com, useportal.net |
| Sequencing | Numbered or indexed section markers (e.g. `01`, `02`…) used as a structural/navigational device instead of unlabeled sections | collection.industries, depoluxe.xyz |
| Layout | Asymmetric or broken-grid composition — offset columns, varied block widths — instead of a flat, even 3-column grid | useportal.net, depoluxe.xyz |
| Voice | Conversational, first-person copy in headings and microcopy, over generic marketing-speak | bymonolog.com, useportal.net |
